```bash

# 執行所有測試
npm run test:e2e
```

#### 3. 編寫單元測試

在實作核心函式時,同步編寫單元測試:

```typescript
// 例如: tests/unit/lottery-logic.test.ts
import { describe, it, expect } from 'vitest';
import { selectRandomWinner } from '@/lib/lottery/random-selector';

describe('selectRandomWinner', () => {
  it('should select a winner from participants', () => {
    const participants = [...];
    const winner = selectRandomWinner(participants);
    expect(participants).toContain(winner);
  });
});
```

#### 4. 手動測試驗證

使用手動測試清單進行人工驗證:

```bash
# 啟動開發伺服器
npm run dev

# 開啟測試清單
# tests/manual/test-checklist.md

# 逐項執行測試
```
