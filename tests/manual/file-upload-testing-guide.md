```csv

正常資料,EMP20252001,,normal@test.com,0912222001
,EMP20252002,,no-name@test.com,0912222002        ← 缺少姓名
無ID者,,,no-id@test.com,0912222003              ← 無 ID
Email錯誤,EMP20252004,,not-an-email,0912222004   ← Email 格式錯誤
重複資料,EMP20252001,,duplicate@test.com,0912222005  ← 重複 ID

```

**測試步驟**: 同標準 CSV 上傳

**預期結果**:
- ✅ 顯示匯入摘要報告
- ✅ 成功：2-3 筆
- ✅ 失敗：3-4 筆
- ✅ 顯示錯誤明細：
  - 「第 2 列：缺少姓名」
  - 「第 3 列：缺少員工編號或身分證字號」
  - 「第 4 列：Email 格式不正確」（或仍成功匯入）
  - 「第 5 列：參與者已存在（重複 ID）」
- ✅ 有效資料仍成功匯入（部分成功）

## 9. 常見問題與解決方案

### Q1: CSV 上傳後中文亂碼？

**A**: 確認 CSV 檔案使用 UTF-8 with BOM 編碼。可用記事本開啟 → 另存新檔 → 編碼選擇「UTF-8」。

---

### Q2: Excel 電話號碼前導 0 消失？

**A**: 在 Excel 中，將電話號碼儲存格格式設為「文字」，或在數字前加單引號 `'0912345678`。

---

### Q3: 上傳 1000 筆資料時瀏覽器當機？

**A**: 這可能是正常的效能限制。建議：
- 分批上傳（每次 500 筆）
- 或使用效能更好的瀏覽器（如 Chrome）

---

### Q4: 測試檔案找不到？

**A**: 執行生成腳本：
```bash
node tests/fixtures/scripts/generate-csv-files.js
```
